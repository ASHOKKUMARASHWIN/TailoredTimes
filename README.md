# TailoredTimes 📰

> **Curating your world, headline by headline.**  
> A personalized, multi-country news aggregator and exam archive with live RSS streaming, topic intelligence, and reading modes.

---

## 🚀 Features

- **Personalized Magazine ("My News / For You"):** Tailored to your selected topics (*AI, Technology, Business, Science, Startups, Education, etc.*) and profession.
- **Top Global Headlines ("Home / World"):** Real-time global breaking news from major international agencies (BBC, Reuters, CNN, Guardian, Al Jazeera, etc.).
- **Multi-Country Domestic Feeds ("My Countries"):** Balanced round-robin domestic news across 100+ nations.
- **Learning & Exam Archive:** 50 High-Yield Study Articles for **CA Students**, plus curated collections for **General Students**, **IELTS Prep**, and **TOEFL Prep**.
- **Personal Library:** 1-click article bookmarking and offline persistence.
- **Contextual Editorial Photography:** Topic-aware non-repeating high-definition editorial visuals with Open Graph metadata parsing.
- **Customizable Preferences:** Full settings panel to update countries, reading formats, topics, and themes.

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express, XML Parser, Open Graph scraper, Mongoose
- **Frontend:** Vanilla HTML5, CSS3 Custom Properties (Dark/Light mode), Modern JavaScript (ES6+)
- **Architecture:** Zero frontend build steps required (Pure SPA)

---

## 📦 Quick Start Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/TailoredTimes.git
   cd TailoredTimes
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the server:**
   ```bash
   npm start
   ```

4. Open your browser at `http://localhost:5000`.

---

## 🌐 Deploy to Production (Render / Railway / Vercel)

1. Create a new repository on GitHub and push this code.
2. Link the repository to **Render.com** (as a **Web Service**).
3. Set Build Command: `npm install`
4. Set Start Command: `npm start`
5. Connect your custom domain in the **Custom Domains** tab.
